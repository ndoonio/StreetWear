# StreetWear
Progettazione e sviluppo autonomo di una piattaforma e-commerce dedicata alla vendita di outfit e abbigliamento streetwear. Il sito comprende un sistema di registrazione e autenticazione degli utenti, un catalogo prodotti con ricerca dinamica, la gestione del carrello e degli ordini e un'area amministrativa riservata per la gestione dei prodotti e il monitoraggio delle vendite. L'applicazione è stata sviluppata seguendo il pattern architetturale MVC, con particolare attenzione alla sicurezza, alla gestione dei dati e alla realizzazione di un'interfaccia responsive.
