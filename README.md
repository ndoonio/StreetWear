# StreetWear — E-commerce di abbigliamento

StreetWear è una piattaforma e-commerce dedicata alla vendita di outfit e abbigliamento streetwear, sviluppata interamente in autonomia come progetto universitario per il corso di **Tecnologie Software per il Web** presso l'Università degli Studi di Salerno.

## Funzionalità principali

- Registrazione, login e gestione delle sessioni utente
- Catalogo prodotti e ricerca dinamica
- Gestione del carrello e degli ordini
- Visualizzazione dello storico degli acquisti
- Area amministrativa per la gestione del catalogo e degli ordini
- Validazione dei form mediante espressioni regolari (Regex)
- Interfaccia responsive

## Tecnologie utilizzate

**Backend:** Java, Servlet, JSP

**Frontend:** HTML5, CSS3, JavaScript, AJAX

**Database:** MySQL, JDBC

**Server:** Apache Tomcat 9

**Architettura:** Model-View-Controller (MVC)

## Obiettivo del progetto

Applicare le conoscenze acquisite durante il percorso universitario, occupandomi autonomamente della progettazione del database, dello sviluppo frontend e backend e dell'integrazione delle funzionalità della piattaforma.

## Esecuzione in locale

Il progetto richiede Java, Apache Tomcat 9, MySQL e il driver JDBC per MySQL.

Per la connessione al database occorre configurare lo schema `streetwear` e la variabile d'ambiente `STREETWEAR_DB_PASSWORD`. Non sono incluse credenziali private.
